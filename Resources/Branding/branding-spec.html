One decision before this ships

The chosen icon (2d Syntax stack) is drawn in the ZaWin palette — Swiss blue #0033A0 and cyan #00A9E0 — because the brainstorm was rendered with the ZaWin design system. The theme tokens below come from docs/mesoneer-design-system.md, whose brand colour is purple #3B2A78. So the dock icon reads cyan while the app chrome reads purple.

Recommended (what this sheet shows): keep the icon exactly as designed, use mesoneer purple for UI chrome, and promote the icon's token colours to the editor's syntax palette — the cyan then reappears as the caret and keyword colour, which ties icon and app together instead of fighting. Alternatives: re-tint the icon purple, or switch the whole app to the ZaWin blue/cyan palette.

Two adjustments were forced by measurement, not taste. (1) The DS doc's status colours only reach 3.4–3.9:1 on white, so light mode darkens them (hue and saturation preserved; dark mode keeps the originals, which pass there). (2) "Primary lightened 30%" for dark mode splits into two tokens: a white label needs the fill darker (#7D67C9) while purple text on a dark surface needs it lighter (#8571CD). One value cannot do both jobs.

Implementing auto + manual

Three states, not two — system (default), light, dark — persisted as a user preference. The mistake to avoid is storing a boolean isDark: it cannot express "follow the OS" and the app stops reacting when the user flips appearance at lunchtime.

  • SwiftUI / AppKit: persist the enum in UserDefaults; apply by setting NSApp.appearance to nil for system, or .aqua / .darkAqua when forced. Read colours through a token type backed by NSColor(name:dynamicProvider:) so the OS resolves them per appearance — a plain if isDark lookup will not refresh when the system flips.
  • Web / Angular: exactly the CSS in this file's <style> — set data-theme on the root element, let @media (prefers-color-scheme: dark) handle the auto case, and persist the choice.
  • Ship both modes with the same token names; only values differ. No component should branch on the mode.

Manrope is the brand typeface and is not a macOS system font — bundle the .ttfs (SIL OFL) or the app silently falls back to the system font, which loses a lot of the brand feel. This sheet is showing you that fallback right now.
